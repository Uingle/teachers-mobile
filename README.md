# Uingle — Teachers Mobile

Mobile app for teachers, built with Expo (React Native).

Uingle is a multi-tenant institution-management SaaS. This app gives teachers access to class schedules, attendance marking, assignments, academic records, and communication tools — directly from their phone.

## Tech Stack

- React Native (Expo)
- TypeScript
- File-based routing via Expo Router

## Getting Started

```bash
npm install
npx expo start
```

Open in Expo Go, an Android emulator, or an iOS simulator.
